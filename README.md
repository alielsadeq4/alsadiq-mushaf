# الصادق — منصة الاستماع الإسلامي

<div dir="rtl">

منصة استماع إسلامية صوتية متكاملة، فاخرة، حديثة، سريعة جدًا، وموجهة أساسًا للهاتف.
تجمع بين القرآن الكريم كاملًا بأصوات نخبة من القرّاء، والرقية الشرعية الموثقة،
وأذكار الصباح والمساء، والصلاة على النبي ﷺ.

**إعداد وتطوير:** علي محمد الصادق © 2026

---

## ✨ الميزات

### 📖 القرآن الكريم (يعمل بشكل كامل ✅)
- جميع سور القرآن الكريم الـ 114
- **10 قرّاء معتمدين** بصوت نقي من mirrors.quranicaudio.com
- تشغيل كامل لكل سورة عبر queue تلقائي للآيات (آية بآية)
- تشغيل مدى محدد من الآيات (من آية X إلى آية Y)
- انتقال تلقائي للآية التالية بعد انتهاء كل آية
- التحكم في السرعة (0.75x — 2x)
- أوضاع التكرار (آية / سورة / قائمة / تالي)
- بحث وفلترة (مكية / مدنية)
- صفحة سورة منفصلة لكل سورة

### 🛡️ الرقية الشرعية (تعمل ✅)
- 6 رقى موثقة (شاملة، تحصين يومي، عين وحسد، سحر، خوف ووسواس، منظمة)
- نصوص مع المراجع لكل مقطع
- تشغيل queue من الآيات الوقائية (الفاتحة، آية الكرسي، أواخر البقرة، المعوذتين)
- تنبيه صريح أن الرقية أسباب والشفاء بيد الله

### 🌅 أذكار الصباح والمساء (تعمل ✅)
- من حصن المسلم للشيخ سعيد بن علي القحطاني
- عدّاد تفاعلي لكل ذكر
- تشغيل تلقائي مع الانتقال للذكر التالي
- عرض الفضل والمصدر لكل ذكر

### 💗 الصلاة على النبي ﷺ (تعمل ✅)
- 5 صيغ موثقة من البخاري ومسلم والترمذي ومالك
- عدّاد مع أهداف اختيارية (10، 100، 500، 1000، مخصص)
- حفظ التقدم تلقائيًا في localStorage

### 🎧 مشغل صوت عالمي (يعمل ✅)
- مشغل عالمي يعمل في جميع الصفحات
- شريط تقدم + وقت + مدة
- التحكم في السرعة والصوت والتكرار
- **Media Session API** (شاشة القفل)
- مؤقت النوم (5، 10، 15، 30، 45، 60 دقيقة، أو نهاية المقطع) — مع fade out هادئ
- استمرار التشغيل أثناء التنقل
- Queue / قائمة انتظار قابلة للترتيب

### 📚 مكتبة شخصية (تعمل ✅)
- متابعة الاستماع (continue listening)
- المفضلة
- قائمة الانتظار (Queue)
- سجل الاستماع
- إحصائيات الاستماع (يومي / أسبوعي / شهري)

### 🔧 نظام مصادر الصوت (مهم ✅)
- مصدر واحد موثوق: **mirrors.quranicaudio.com/everyayah**
- مجاني تمامًا — **بدون مفتاح API**
- يعمل إلى أجل غير محدود
- قسم مخصص في الإعدادات لفحص المصادر
- Fallback تلقائي للقارئ الاحتياطي عند فشل التشغيل
- شفافية كاملة في المصادر والتراخيص

### 💾 نظام التنزيلات الفعلي (يعمل ✅)
- تنزيل السور كاملة (queue من الآيات)
- تخزين في IndexedDB (Blob storage)
- شريط تقدم لكل تنزيل
- عرض المساحة المستخدمة
- حذف التنزيلات
- استماع للتنزيلات بدون إنترنت

### 🔌 PWA و Offline (تعمل ✅)
- قابل للتثبيت كتطبيق على الهاتف والكمبيوتر
- Service Worker + Cache strategies ذكية
- تنبيه عند توفر تحديث جديد
- صفحة Offline مخصصة
- Manifest مع shortcuts للأقسام الرئيسية

### 🌓 الوضع الليلي (يعمل ✅)
- Light / Dark / System
- يحفظ اختيار المستخدم
- دعم كامل لـ RTL

### 🔒 الخصوصية أولاً
- لا نجمع أي بيانات شخصية
- جميع البيانات محفوظة محليًا (localStorage + IndexedDB)
- لا توجد ملفات تعريف ارتباط للتتبع
- لا توجد أدوات تحليلية

## 🛠️ التقنية المستخدمة

- **Framework:** Next.js 16 (App Router) + Turbopack
- **Language:** TypeScript 5
- **Styling:** Tailwind CSS 4 + shadcn/ui (New York style)
- **State Management:** Zustand
- **Storage:** localStorage (إعدادات) + IndexedDB (تنزيلات)
- **PWA:** Service Worker + Web App Manifest
- **Audio:** HTML5 Audio API + Media Session API
- **Fonts:** Cairo (UI) + Amiri (Quran) + Noto Kufi Arabic

## 📥 التثبيت والتشغيل المحلي

### المتطلبات
- Node.js 18.17 أو أحدث
- npm

### الخطوات

```bash
# 1. استنساخ المستودع
git clone https://github.com/USERNAME/sadik.git
cd sadik

# 2. تثبيت الحزم
npm install

# 3. نسخ ملف البيئة (اختياري — يعمل بدونه)
cp .env.example .env.local

# 4. التشغيل في وضع التطوير
npm run dev

# 5. افتح المتصفح على
http://localhost:3000
```

## ☁️ النشر على Vercel

1. ارفع المشروع إلى GitHub
2. اذهب إلى [vercel.com](https://vercel.com) وادخل بحساب GitHub
3. اختر المستودع — سيكتشف Vercel أنه مشروع Next.js تلقائيًا
4. **لا حاجة لأي متغيرات بيئة** — المنصة تعمل بدون مفاتيح API
5. اضغط Deploy — ستحصل على رابط مباشر في دقيقة
